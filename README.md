# RusTab — электронные таблицы на Rust

Русскоязычный настольный прототип электронной таблицы для Windows. Проект создан как стартовая основа, а не как полная замена Excel или LibreOffice.

## Возможности прототипа
- Окно Windows с русским интерфейсом.
- Открытие `.xlsx`, `.xls`, `.xlsm` через библиотеку calamine.
- Импорт простых `.csv`.
- Сохранение в `.xlsx`.
- Табличная сетка, выбор ячейки и строка ввода `fx`.
- Ограниченные формулы для простых ссылок/чисел и операций `+`, `-`, `*`, `/`.

## Сборка на Windows
1. Установите Rust с https://rustup.rs/
2. Установите Visual Studio Build Tools с компонентом **Desktop development with C++**.
3. Распакуйте проект.
4. В папке проекта выполните:

```powershell
cargo run
```

Для сборки исполняемого файла:

```powershell
cargo build --release
```

Файл появится в `target\release\rustab.exe`.

## Ограничения
- Формулы пока не совместимы полностью с Excel; это лишь простейший демонстрационный вычислитель.
- Для `.xls` чтение зависит от возможностей `calamine`; сохранение выполняется только в `.xlsx`.
- Импорт CSV в этой версии рассчитан на простой CSV с запятыми и не является полноценным CSV-парсером.
- Открывается первый лист книги; листы, форматирование, диаграммы, сводные таблицы, макросы и совместная работа пока не реализованы.
- Веб-версия потребует отдельного интерфейса и серверной/браузерной архитектуры. Rust-код вычислений можно будет вынести в общую библиотеку, а веб-интерфейс сделать на WebAssembly.

## План развития
1. Полноценная модель книги: несколько листов, строки/столбцы, выделение диапазонов.
2. Формулы: `СУММ`, `СРЗНАЧ`, `МИН`, `МАКС`, ссылки на диапазоны, зависимости и пересчёт.
3. Форматирование ячеек, копирование/вставка, отмена/повтор.
4. Диаграммы, фильтры, поиск и замена.
5. Тесты совместимости с файлами Excel.
6. Отдельная веб-версия для GitHub Pages или собственного хостинга.

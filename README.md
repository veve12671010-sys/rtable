# RusTab — русская электронная таблица (прототип)

Проект включает:
- **Windows-приложение на Rust** (`cargo run`).
- **Веб-версию** в папке `web/`, которую можно опубликовать на GitHub Pages.
- Импорт Excel/CSV и экспорт XLSX в веб-версии через SheetJS CDN.
- Несколько листов, формульную строку, простые арифметические формулы, `СУММ`, `СРЗНАЧ`, `МИН`, `МАКС`, выделение жирным и цвет заливки ячейки в веб-версии.

## Запуск Windows-приложения

Установите Rust с https://rustup.rs/ и Visual Studio Build Tools с компонентом Desktop development with C++.
В терминале в корне проекта:

```powershell
cargo run
cargo build --release
```

EXE будет в `target\release\rustab.exe`, если сборка завершилась успешно.

## Запуск веб-версии локально

Можно открыть `web/index.html` в современном браузере. Для более надёжного поведения запустите простой локальный сервер:

```powershell
cd web
py -m http.server 8000
```

Откройте http://localhost:8000. Импорт/экспорт Excel использует SheetJS CDN, поэтому для этой функции нужен интернет.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите файлы проекта.
2. В настройках репозитория откройте **Settings → Pages**.
3. Для источника выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` — но в этом случае `index.html` нужно положить в корень репозитория или настроить публикацию папки `web` через отдельную ветку/действие.
4. Самый простой вариант: скопируйте содержимое `web/` в корень отдельного репозитория для сайта и включите Pages.

## Ограничения и честный статус

Это MVP, не полная замена Excel/LibreOffice:
- движок формул ограниченный; не поддерживаются все функции Excel, сложные зависимости, именованные диапазоны, массивы и обработка ошибок на уровне Excel;
- веб-импорт читает данные и формулы базово, но не сохраняет всё форматирование, макросы, диаграммы, сводные таблицы, проверки данных и прочие особенности исходной книги;
- `.xlsm` не запускает и не переносит макросы;
- настольная версия Rust пока значительно проще веб-прототипа;
- импорт PDF не реализован: PDF не является книгой Excel, для него нужен отдельный конвертер/импорт таблиц;
- перед использованием с важными файлами обязательно тестируйте копии данных.

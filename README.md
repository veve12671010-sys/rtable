# rtable — табличный процессор на Rust

Русские имена функций как в LibreOffice (СУММ, ЕСЛИ, СЧЁТЕСЛИ, ОКРУГЛ…), аргументы через `;`, десятичная запятая.
Открывает xlsx / xlsm / xls / xlsb / ods, сохраняет в xlsx (формулы пишутся в файл на английском, Excel их понимает).

## Сборка exe на Windows
1. Установите Rust: https://rustup.rs (при установке согласитесь поставить «Visual Studio C++ Build Tools»).
2. В папке проекта: `cargo build --release`
3. Готовый файл: `target\release\rtable.exe`

Либо загрузите проект на GitHub: вкладка Actions → «Сборка exe для Windows» → скачайте artifact.

## Горячие клавиши
Стрелки — перемещение, любой символ или F2 — ввод, Enter — подтвердить (вниз), Esc — отмена, Delete — очистить, Ctrl+S / Ctrl+O — сохранить / открыть.

## Не поддерживается
Стили и форматы ячеек, диаграммы, ссылки между листами, даты как даты (показываются числом), функции вне списка в меню «Функции».
